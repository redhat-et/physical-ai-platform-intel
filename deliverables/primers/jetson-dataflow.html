Key architectural point: All vision accelerators share the NVMM buffer pool — frames never touch CPU memory in the hot path. This is what makes Jetson's vision pipeline fast: a frame captured by VI flows through ISP → VIC → DLA → GPU entirely in DMA buffers. DeepStream and Isaac ROS (NITROS) are two software frameworks that orchestrate these hardware elements — DeepStream for streaming analytics, Isaac ROS for robotics perception. Both use GStreamer-style pipeline composition but with GPU-accelerated plugins replacing CPU processing.

Non-vision sensors (IMU, LiDAR, force/torque) bypass NVMM and arrive via CPU — they're fused with vision data at the GPU or application layer. SE and FSI operate independently of the media pipeline: SE handles crypto (TLS for camera streams, secure boot), FSI monitors the SoC for safety-critical applications.
