Vision pipeline: All vision accelerators share the NVMM buffer pool — frames never touch CPU memory in the hot path. A frame captured by VI flows through ISP → VIC → DLA → GPU entirely in DMA buffers. DeepStream and Isaac ROS (NITROS) orchestrate these hardware elements — DeepStream for streaming analytics, Isaac ROS for robotics perception.

Audio pipeline: The APE (Audio Processing Engine) is a self-contained subsystem with its own DMA engine (ADMA, 20 channels) and a crossbar switch (AXBAR) routing audio through hardware accelerators — sample rate conversion (SFC, ASRC), multiplexing (AMX/ADX), mixing, volume control (MVC), and equalization (OPE). On Orin, the ADSP (Cortex-A9) is present in hardware but locked down — not accessible to developers. Audio processing beyond AHUB hardware runs on the CPU via ALSA/ASoC. On Thor, the ADSP moves to dual Cadence HiFi 5 DSP cores in an always-on domain.

Sensor pipeline: The SPE (Sensor Processing Engine) — an ARM Cortex-R5 at 200 MHz running FreeRTOS in the Always-On domain — can independently poll IMU and other I2C/SPI sensors, hardware-timestamp them via the GTE, and forward pre-processed data to the main CPU via IVC shared memory. This is the intended low-latency sensor path. Sensor fusion itself splits: visual-inertial SLAM (cuVSLAM) runs on GPU; EKF-based multi-sensor fusion runs on CPU. Neither DLA nor PVA is used for IMU fusion.

LiDAR: Connects via PCIe or Ethernet. Point cloud processing runs on GPU via CUDA-PCL (up to 10× faster than CPU). No dedicated hardware accelerator for point clouds.

Robotics I/O: Orin has 2× on-chip MTTCAN controllers (CAN FD, up to 15 Mbps) for force/torque sensors and motor drives. No native EtherCAT hardware — EtherCAT requires a software master (SOEM or acontis EC-Master) over standard Ethernet. Thor adds built-in CAN transceivers and the Holoscan Sensor Bridge, which streams diverse sensors over Ethernet directly into GPU memory.

SE and FSI operate independently: SE handles crypto (TLS, secure boot), FSI monitors the SoC for safety-critical applications. Orin has no ADC — analog sensors require an external ADC module.
